    練習前請先閱讀

    • 絕對不要在水中、泡澡、游泳、開車，或站著時練習。
    • 請坐著或躺著，在安全的地方練習。
    • 手腳發麻、頭暈、刺痛是常見反應；如果感到不舒服，請停止並恢復正常呼吸。
    • 孕婦、癲癇、心臟或血管相關疾病、高血壓，或有其他健康狀況的人，請先詢問醫師。
    • 不要硬撐閉氣時間。
